> **STATUS: verde, NÃO commitado.** Firmware: **1.2.390**.
> `tests\run_tests.bat` **391/391 OK** (exit 0) + `run_slow.bat` **7/7**.
> Handoff para retomada: leia `skill.md` → `Projeto.md` → `marco.md` §8 → este doc.

## 1. Objetivo da sessão

Fechar o primeiro item da fila pós-1.2.386: **`-s <seção>` + `-r` falhava no
link** (`LNK2001: unresolved external symbol label_<entry>`, exit 5) quando a
seção filtrada não era a seção do entrypoint.

Escopo entregue: apenas o **link**. O comportamento do `.exe` reconstruído em
PE real continua limitado pela **D-19 fatia 2** (`exc` ainda dá `0xC0000005`).

## 2. Causa raiz

* O header do `.asm` gerado emitia só `global label_<entryVA>`.
* A **definição** `label_<entryVA>:` só nascia no walker de código da seção
  do entrypoint.
* Com `-s` apontando para outra seção, o contrato do filtro manda emitir a
  seção do entry como dados (`db`/chunks) → o label nunca era definido.
* O `link.exe` recebia `/ENTRY:label_<entryVA>` e abortava com `LNK2001`.
* `-s .text` funcionava porque a seção do entry era justamente a seção
  desassemblada.

Reproduções (antes do fix):

```bat
out\dexter.exe tests\exc.exe -s .rdata -native -r -O tests\out\x.exe -o tests\out\x.asm -q
rem exit 5; LINK : error LNK2001: unresolved external symbol label_140001125

out\dexter.exe tests\exc.exe -s .rdata -r -O tests\out\x.exe -o tests\out\x.asm -q
rem exit 5 (o caminho db também falhava)
```

## 3. Fix implementado

Novo local `.emit_entry_alias` em `src/gen/rebuild.asm` (chamado em
`.free_syms`, depois de todas as seções). Ele localiza a seção que contém o
`PeImage.entry_point` e, **no fim do arquivo**, emite:

```text
label_<entryVA> equ label_<secVA> + 0x<delta>
```

Onde `label_<secVA>` é o `lab0` que toda seção emitida já produz
(`db`/chunks/`bss`) e `delta = entry_rva - sec_vaddr`.

Guardas (todas com teste):

| Condição | Ação | Motivo |
|---|---|---|
| sem `-r` | não emite | geração normal não precisa |
| `-m bin` | não emite | `-f bin` não usa `/ENTRY` |
| sem `-s` | não emite | walker de código define o label |
| `-s` == seção do entry | não emite | evita definição duplicada |
| `delta == 0` | não emite | o label da seção já é o entry; evita `label_X equ label_X + 0` |
| seção do entry não achada | não emite | direção segura: não inventa símbolo |

A emissão no fim elimina forward reference (`equ` referencia label já
definido). `equ` é absoluto e não gera relocação — correto para `/ENTRY`.

Detalhe arquitetural: `docs/adr/0002-entry-label-equ.md`.

## 9. Armadilhas conhecidas (não repetir)

1. **Default de `-o` é `<input>.asm`.** Rodar `dexter tests\tiny32.exe -v` sem
   `-o` **sobrescreveu** `tests\tiny32.asm` (fonte do corpus) e derrubou 14
   checks de x32. Restaurado com `git checkout -- tests/tiny32.asm`; `[0]`
   agora pega isso.
2. **`nasm` do PATH** pode ser o 2.16.01 do Strawberry; o projeto usa
   `C:\Nasm\nasm.exe` (3.01). Use o caminho absoluto.
3. **`ctx` escreve banner em stderr**; no PowerShell isso vira
   `NativeCommandError` e exit 1 aparente. O comando funciona — confira a
   mensagem e o efeito, não só `$LASTEXITCODE`.
4. **Slots de spill** na ABI Win64: qwords em múltiplos de 8 (`D-13`).
   O helper usa `[rbp-48..-72]` (frame de 40 B) e `sub rsp,32` por call.
5. **`-s` + `-r` fecha só o link.** Não prometer comportamento: a D-19 2
   continua aberta.
