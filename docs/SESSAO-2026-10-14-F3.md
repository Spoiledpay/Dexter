## 2. Bugs reais corrigidos (causa-raiz provada por `fc` + listing)

Os 4 diffs finais eram 2 classes; ambas resolvidas:

1. **`0F AB` (BTS) → `bt`** (2×). `semantics.asm .l2_bt` sobrescrevia o
   mnemônico da tabela com `s_bt` **fixo** para A3/AB/B3/BB, então
   BTS/BTR/BTC nunca saíam. Fix: escolher por `Insn.opcode`
   (A3=bt, AB=bts, B3=btr, BB=btc) — mesmo padrão do `.l2_ba` (grupo 8).
   De quebra a tabela 2-byte foi alinhada: `B3→s_btr`, `BB→s_btc`.
   Evidência: `hexva.py 0x140040BE9` (orig `48 0f a3 d0` / `48 0f ab d0`;
   só o 2º byte diferia).

2. **`D3` (shr Ev) → `D2` (shr Eb)** (2×). Instrução `shr [reg-4], cl`:
   o emitter decidia o prefixo de tamanho por "existe algum operando REG?",
   e o `cl` (op1) fazia a checagem achar que o tamanho era byte → sem
   prefixo → o nasm default é byte → opcode `D2`. Fix em `.fo_mem`:
   para opcode `D2/D3` (1 byte), o `cl` **não** determina o tamanho; força
   o prefixo por `op0.size`. Evidência: listing
   `shr [r10+0xFFFFFFFC], cl` → `41 D2 6A FC` (orig `41 D3 6A FC`);
   fix → `41 D3 6A FC`.

## 3. Classes de exatidão fechadas (todas com prova `fc`/listing)

1. disp-zero com bytes → `db` (nasm minimiza `[reg+0x0]`).
2. nop longo (`66 90` etc.) → `db`.
3. jcc/jmp rel8→`short`, rel32→`strict near` (`near` puro é *hint*;
   ponto-fixo local do nasm em distâncias ~124-127; `short` é exato).
4. `jmp` no caminho vivo (a regra estava em código morto).
5. imm8 negativo como `-0x` (0xFF nu virava imm32).
6. grp2 com `rcl` (`shl` virava `shr`).
7. r8hi sempre sem REX (AH→SPL) + REX-inútil→db em bin.
8. C0 par → size 1 (`shr bl`, não `shr ebx`).
9. tbl2 `AB→s_bts`; depois `B3→s_btr`, `BB→s_btc`.
10. **shift por CL MEM (D2/D3): prefixo explícito por op0.size.**

## 7. Armadilhas registradas (ler antes de operar)

  Veredito só via `cmd /v:on /c "exe & echo X=!errorlevel!"` ou `if !errorlevel!`
  dentro de `.bat`.
- **`findstr` é case-sensitive** (labels em HEX maiúsculo: `label_140011B50`).
- **`python -c` com quoting complexo quebra silencioso** no PowerShell;
  preferir arquivos `.py` em `%TEMP%\opencode\htest\`.
- **`&` nu é proibido** no shell (use comandos separados; dentro de string
  quotada p/ `cmd /v:on /c "... & ..."` é OK).
