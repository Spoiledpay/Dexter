## 7. Armadilhas registradas (ler antes de operar)

- **Exit codes do shell NÃO são confiáveis p/ exe direto** (`tests\tiny.exe` reportava 1, real 42; background reportou 1 p/ suíte com `BAT_EXIT=0`). Veredito só via `cmd /v:on /c "exe & echo X=!errorlevel!"` ou `if !errorlevel!` dentro de `.bat`.
- **`findstr` é case-sensitive** (labels usam HEX maiúsculo: `label_140011B50`).
- **`python -c` com quoting complexo quebra silencioso** no invólucro PowerShell (saída vazia sem erro). Preferir arquivos `.py` em `%TEMP%\opencode\htest\`.
- **`&` nu é proibido** no shell (usar comandos separados; dentro de string quotada p/ `cmd /v:on /c "... & ..."` OK).
- **Nunca editar repo via shell** (só `edit`); shell só cria temp novo ou lê. `del` só em `tests/out/` (ignorado) e um por vez (cadeia aborta no 1º ausente).
- **`fc /b` em 2 MB despeja 60k linhas** — usar os scripts de resumo, nunca o output cru.
- **nasm tem limites reais**: `near` puro é hint (usar `strict near`); `short` é exato; labels duplicadas de MESMO valor são legais; `times`/seções em `-f bin` alinham (vstart testado e descartado p/ bin — regra mesma-seção no lugar); `resb` no nasm win64 vira zeros (nunca nobits); seções `.bss/.tls/.xdata` somem no `link.exe` (D-19); `patch_dirs` copia RVAs cegamente.
- **Oráculos externos**: capstone 5.0.7 (`Cs(CS_ARCH_X86, CS_MODE_64)`) como verdade p/ decode; `fc /b` como verdade p/ bytes.
- **Fixture `tests\memsz.exe` (em `out\`) dá AV (-1073741819) mesmo construído da fonte** — pré-existente, `[34]` não o executa; sem run até segunda ordem.
- **`tests\t32.exe` sem fonte** (oráculo = exit do original = 42); `strings.rebuild.exe` em `tests/` é sobra antiga; `for.exe` removido a pedido (quarentena AV).
- **Cuidado/[regressão]**: mudanças no emissor/decoder afetam goldens win64 (`ref_native/`, `[12]`); suíte completa antes de todo commit; `version.bin` sobe sozinho a cada build.
